01Live since July 2026

Daily Defect Log

Power Apps canvas · SharePoint lists · Power Automate

A tablet app the production floor uses to log defects, red tags, and daily built and boxed counts the moment they happen. It replaced paper sign-off binders and feeds two live dashboards.

Features

  • Defect entry with unit serial, inspection point, inspector, fix and photos
  • Location choices filtered by product, so entries can't land on the wrong line
  • Production dashboard: rolling 3-day defect rate, built and boxed totals, defects per unit, daily trend and top defect categories
  • Red tag dashboard: top parts, top defects, responsible party, and open tags by age
  • Searchable defect records with product, location, inspector and sort filters
  • One-screen daily counts for assembled and boxed units by product
  • Tool and equipment requests that route to the tool catalog and the engineering board
  • Dark glass interface, readable on the floor's tablets

610 defects in the first three months, all traceable to a unit serial number.

Daily Quality Report

Power Automate · SharePoint · Outlook

A scheduled flow that emails the team every morning with the previous day's numbers, so nobody builds a report by hand.

Features

  • Units built and boxed, defects and red tags for the day
  • Defects grouped by inspection point, with the busiest station first
  • Sorted, formatted HTML tables built inside the flow

Same-day visibility for supervisors with zero manual prep.

How the flow runs
Recurrence, every weekday morning → Get items: yesterday's defects, red tags and unit counts → Group and count by inspection point and category → Build sorted HTML tables → Send email to the quality and production team

Red Tag Quality Management

Power Apps · six SharePoint lists · Power Automate

The next stage for nonconforming parts: one app that carries a red tag from submission through investigation, disposition, corrective action and closure.

Features

  • Live quality dashboard: red tags, unresolved count, affected quantity, assembled vs boxed
  • Red tags charted by product and by part
  • Investigation, disposition and verification steps with owners
  • Master parts list and a review queue for legacy imports

Built on the cleaned red tag data: part numbers standardized against the BOMs and reported by quantity affected.

05Built, awaiting licensing

Production Command Center

Power Apps · Dataverse · Power Automate sync to SharePoint

A planning app for managers that assigns work by each person's certifications and available time, and refines cycle times with a built-in timer.

Features

  • Role-based sign-in: production, inventory and admin views
  • Work assignments generated from certifications and available hours
  • Database of jobs, people, BOMs, tools, fixtures, test equipment and work cells
  • Production kiosk with a task timer for cycle-time data
  • Training sign-off, a certification matrix and an inventory picking kiosk
  • Two-way sync of tools and fixtures with the SharePoint catalog

Licensing plan written: Premium for a handful of managers, standard licenses for the floor.

Data and automation

SharePoint · Power Automate · scripting

The plumbing behind the apps: clean reference data and the jobs that keep it current.

  • Unit Log. Every unit since December 2025 by model and configuration, with assembled and boxed dates.
  • Morning unit setup. The day's production units are created in the build-sheet system in one step instead of one at a time.
  • Master Parts List. Material cost and quantity per unit on every part, so scrap and vendor credits can be priced.
  • Change tracking. 30+ engineering changes in 2026 traced to the first affected serial number through the change request process.
  • Fixture requests. Repair and new-fixture requests routed straight to the engineering team's board.
07Live

Quality dashboards

HTML · JavaScript · live SharePoint data

Browser dashboards that read the defect, red tag and unit-count lists directly, for managers who don't use Power BI. They open from the quality team's SharePoint site, with no extra licenses.

Features

  • Filters for product, location, date range and sort order
  • Defects per affected unit, calculated from unit serial numbers
  • Product comparison of built, boxed and defect rates
  • Daily built and boxed volume against the rolling 3-day defect rate
  • Red tags by responsible party and the top 20 parts by affected units
  • Sortable issue records with part number and part name search

782 red tag issues and 2,015 affected units in one filterable view.
